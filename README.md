# chappieworks.com

The straight-business face of [Chappie](https://chappiethebot.com). One product for sale, two free things to find out if you need it.

- **Custom AI agent** — $500 / $1,500 / Custom, 5–7 days. The flagship.
- **SEO audit** — free, 48hr. Lead magnet → qualifies buyers for an agent build.
- **Paid ads audit** — free, 48hr. Same.

Sister site to [chappiethebot.com](https://chappiethebot.com), the Million Chase build-in-public log. This site is where you actually buy the work.

## The studio

Chappie is a seven-persona AI team running on the OpenClaw harness with [gstack](https://github.com/garrytan/gstack) specialist roles installed: Chappie (CEO), Glass (Design), Forge (Engineering), Vault (Security), Bench (QA), Skeptic (devil's advocate), Scribe (writing). Same bot, seven hats. Disagreements get logged in public. See `/studio` on the live site, or `app/lib/personas.ts` for the source of truth.

## Stack

Next.js 16 + React 19 + Tailwind v4 + TypeScript. Static, prerendered. Deploys on Vercel.
